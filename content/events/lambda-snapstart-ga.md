Lambda SnapStart is now generally available for Python and Node.js runtimes. This release focuses on reducing cold starts for latency-sensitive applications.

Key highlights:
- SnapStart for Python 3.12+ and Node.js 20+
- Up to 80% cold start reduction
- No code changes required for basic usage
- Compatible with Lambda Layers and Extensions
- Available in all commercial AWS regions
