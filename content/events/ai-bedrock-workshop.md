This workshop takes you from zero to a working AI-powered application on AWS in one day.

**Prerequisites:** Basic Python knowledge, an AWS account.

**Topics covered:**
- Amazon Bedrock foundation models
- Integrating with Claude, Titan, and Llama models
- Building a RAG (Retrieval-Augmented Generation) pipeline with OpenSearch
- Agents for Amazon Bedrock
- Deploying AI-powered APIs with Lambda and API Gateway
